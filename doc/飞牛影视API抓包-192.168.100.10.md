> 探测方式：模拟客户端 Authx 签名 + 批量 API 请求（等效于抓包分析）

## 1. 认证

### 1.1 登录（可用 ✅）

**POST** `/v/api/v1/login`

```json
{
  "app_name": "trimemedia-web",
  "username": "home",
  "password": "明文密码",
  "nonce": "123456"
}
```

**响应：**
```json
{ "code": 0, "data": { "token": "d86fe85cff064fe8b577..." } }
```

> 也可用 **POST** `/v/api/v2/user/loginByPassword`，密码需 SHA256 哈希。

### 1.2 Authx 签名

所有请求 Header 需携带：
- `Authx: nonce=...&timestamp=...&sign=...`
- `Authorization: {token}`
- `Cookie: mode=relay`

签名算法（与 App 一致）：
```
sign = MD5(apiKey + "_" + urlPath + "_" + nonce + "_" + timestamp + "_" + MD5(body) + "_" + apiSecret)
```

**注意：** POST 请求 body 必须与实际发送的 JSON 字符串完全一致（不能有多余空格），否则返回 `code: 5000 invalid sign`。

| 方法 | 路径 | 状态 | 说明 |

**POST /v/api/v1/stream 请求体：**
```json
{
  "media_guid": "...",
  "ip": "md5hex(用户名)",
  "level": 1,

  "nonce": "123456"

```

**subtitle_streams 实测（翘楚 strm 文件）：**
```json
{
  "guid": "2ae941949d6b49f49e8e1b47f2a61493",
  "codec_name": "mov_text",
  "codec_type": "subtitle",
  "language": "und",
  "index": 3,
  "is_default": 1,
  "is_external": 0,
  "is_bitmap": 0
```

> **重要：** 字幕在列表中是第 0 条，但容器内真实 `index=3`（不是 0）！

**direct_link_qualities：** 夸克云盘直链（strm 文件）

## 8. 字幕接口（重点 ⚠️）

| 方法 | 路径 | 状态 | 说明 |
|------|------|------|------|
| GET | `/v/api/v1/media/range/{subtitle_guid}` | **403** | 无权限 |
| GET | `/v/api/v1/media/range/{media_guid}?stream_index=3` | **400** | strm 文件不支持 |
| GET | `/v/api/v1/media/range/{media_guid}?stream_index=3&format=srt` | **400** | 同上 |
| GET | `/v/api/v1/media/subtitle/{media_guid}` | **501** | Not Implemented |
| GET | `/v/api/v1/subtitle/{media_guid}` | **501** | Not Implemented |
| POST | `/v/api/v1/media/subtitle/extract` | **501** | Not Implemented |
| GET | `/v/api/v1/subtitle/list` | **501** | Not Implemented |

**结论：** 在你这台服务器上，**strm + 夸克直链** 场景下，HTTP API **无法提取内嵌 mov_text 字幕**。501 端点尚未实现，media/range 字幕提取对 strm 返回 400。

**可行替代方案：**
1. 播放器切 **MPV 内核**（本地 demux 字幕）
2. 手动加载外部 **SRT/VTT** 文件
3. 使用本地 mkv/mp4 而非 strm 网盘串流

## 13. 完整播放流程（实测可用）

```
1. POST /v/api/v1/login                          → token
2. GET  /v/api/v1/mediadb/list                    → 媒体库 GUID
3. POST /v/api/v1/item/list                       → 条目列表
4. GET  /v/api/v1/episode/list/{season_guid}      → 集列表
5. POST /v/api/v1/play/info                       → media_guid + guids
6. POST /v/api/v1/stream                          → 直链/转码 URL + subtitle_streams
7. 播放 direct_link_qualities[0].url              → 夸克直链
8. POST /v/api/v1/play/record                     → 上报进度
```
